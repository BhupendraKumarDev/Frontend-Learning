## Open a practice page

Open this repository folder in VS Code, then open the day's `index.html` file in a browser. Some exercises use online images, so those images need an internet connection.

## Daily GitHub updates

After adding a day's practice, review it and use a clear commit message, for example:

```bash
git add .
git commit -m "Day 17: practice CSS selectors"
git push
```
