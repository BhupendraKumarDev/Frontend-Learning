P Tag- The paragraph tag is used to define a paragraph of text. It automatically starts content on a new line and adds spacing before and after it.

BR Tag. Uded to break the current line and continue content on the next line
It does not create a new paragraph.

B Tag - Display text in bold style without adding any semantic importantce.

Strong Tag - Indicates that the content is important and usually displays it in bold.

I Tag - Display text in italic style for visual presentation.

Em tag - Emphasizes text and usually displays it in italic style.

U Tag - underlines the text to draw attntion to it.

Mark Tag - Highlishts text with a backgrount color to make it noticeable.

small tag - Display text in a smaller font size than normal text.

SUP Tag - Used to display superscript text.

Example: x2+ y2 = z2

SUB Tag - Used to display subscript text.

Example: H2O and CO2

Del Tag - Represents deleted or removed content.
